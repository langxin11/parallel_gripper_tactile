# 纯触觉接触变化检测、摩擦能力估计与力调度

所属主题：[自适应抓取](adaptive-grasping.md)。三条路线的关系与选择见主题总览。

`friction-estimate` 仅使用左右逐 taxel 三轴力及其历史进行在线检测和估计。保持阶段使用实测双侧
切向合力与冻结的摩擦候选计算法向目标，底层控制器跟踪平均单侧目标力。

## 在线与离线边界

在线链路为：接触滞回筛选 → 触觉特征 → 变化评分与持续确认 → 起滑前窗口分位估计 → 触觉力调度。
`TactileFrictionEstimator.update_slip_detector(features, dt)` 接口没有外部载荷、探测命令、
真实摩擦系数、位移或速度参数。

仿真仍施加世界 +Y 探测载荷与重力方向动态载荷。它们保存在 `load_ground_truth` 等 trace 列中，
只用于实验施加载荷及离线评分。真实摩擦与物体运动也仅用于物理模型和评分。

## 触觉特征与确认

对滞回筛选后的有效 taxel，计算法向力、切向模及局部比值。法向零分母不参与统计。采用
10 ms EMA 平滑有效点力；接触集合改变时重建窗口，避免集合跳变制造分布变化。

- `rho_global = sum(Ft_i) / sum(Fn_i)`：有效点的切向模之和除以法向力之和。
- `rho_q95`：局部比值 95% 分位数。
- `high_utilization_fraction`：比值达到当前 q95 的 85% 的有效点比例。
- `distribution_change`：切向力归一化空间分布与约 60 ms 前参考的 L1 距离。
- 三种变化率：60 ms 窗口的线性拟合斜率。
- 左右法向和切向力不对称性：两侧差的绝对值除以两侧和。

检测器要求整体比值相对本轮最低值上升至少 0.03，且曾有至少 0.08/s 的正斜率，才进入可检测状态。
饱和证据为 `clip(1-max(d_rho_global_dt,0)/arming_slope,0,1)`；分布变化和不对称性按配置尺度
归一化。四项权重默认为 0.7、0.15、0.05、0.1，并按权重和归一化。整体比值/q95 小于 0.8 时
禁止确认总体事件，以抑制局部载荷变化造成的过早触发。全部参数位于 task 的 `tactile_slip` 段。

状态为 `stable`、`incipient_slip_candidate`、`incipient_slip_confirmed`：
评分达到 0.55 进入候选，低于 0.4 撤销；连续至少 12 ms 达到 0.65 后确认并锁存。
确认计时在评分低于确认阈值时清零。未确认事件不生成摩擦估计。

这是一种可解释的触觉接触变化/起滑代理，不能单凭评分确认真实微滑。停止加载、主动改变预载或接触
重分布也可能形成相似力信号；现有结果只验证固定预载、慢速探测协议。现有 MuJoCo 模型没有独立柱体
形变观测，尚不能证明该评分识别了局部静摩擦到滑动摩擦的转变。

## 估计与目标力

候选期间暂停估计窗口采样。确认后对候选开始前窗口取配置高分位，并乘小于 1 的折减系数、裁剪到
配置上下限，冻结 `mu_raw` 和 `mu_hat`。未确认或样本不足时保留显式回退值。折减产生保守候选，
并非具有概率保证的摩擦下界。

保持阶段平均单侧法向目标为
`clip(safety_factor * (Ft_left + Ft_right) / (2 * mu_hat), min_force, max_force)`，
其中每侧 Ft 是该侧触觉三轴力先求合力、再取切向模。目标仍受变化率限制。此处与检测使用的有效点
切向模之和不同，避免把内部相互抵消的剪切重复算作外部支撑。侧向支撑丢失时，该测量可能低估外载，
因此当前保持结果不能推广为任意滑落情况下的恢复保证。

## 运行与图表

```bash
uv run pgt run friction-estimate \
  --experiment dm_gripper/friction_estimation \
  --set task=friction_probe/hardware_scale_nominal
```

保留 `trace.csv`、`metrics.json`、输入快照、有效参数、manifest。默认 summary 模式生成主图；
`--set execution.plot_mode=diagnostic` 额外生成逐点图，科学失败保留诊断。
主图包含触觉力、利用率、评分、冻结估计和离线位移；诊断图给出逐点时序与事件快照。
没有确认事件时不生成确认快照；确认后事件评分锁存，特征继续更新。
trace 记录特征、状态、阈值、`mu_raw`／`mu_hat`、逐点力与离线真值。兼容残差列恒为零；
检测参数以 `tactile_slip` 为准，`estimator` 只控制估计窗口、分位数、折减、回退与摩擦范围。

metrics 记录检测依据、确认时完整特征、相对误差、探测超限和保持成功标志。检测时刻
`probe_detection_time_s` 相对于探测开始，图中使用仿真绝对时间。

## 当前固定种子结果

| 场景 | 真值 μ | 候选 μ | 探测/恢复最大位移 mm | 保持最大位移 mm |
| --- | ---: | ---: | ---: | ---: |
| 低摩擦 | 0.35 | 0.295 | 0.0063 | 0.0015 |
| 名义 | 0.8 | 0.671 | 0.0114 | 0.0070 |
| 高摩擦 | 1.2 | 0.950 | 0.0172 | 0.0107 |
| 两倍噪声 | 0.8 | 0.652 | 0.0114 | 0.0068 |
| 硬件阈值 | 0.8 | 0.721 | 0.9841 | 0.0124 |

以上五例满足原验收门槛；低探测载荷负例不确认事件并使用回退值。它们是单一固定 seed 的工程回归，
不是多种子泛化结论。硬件阈值场景使用 0.5 N 进入、0.25 N 退出、4 N/侧预载，探测速度从
1.5 N/s 降为 1 N/s：原速度在新检测器下产生 2.51 mm 位移超限，降速后通过 2 mm 门槛。

传感器截图给出的单点量程为 Fx/Fy ±4 N、Fz 15 N，标称分辨率优于 ±0.05 N。0.5 N 是阈值候选，
并非由量程证明的最优阈值。分辨率也不能直接视为量化步长或噪声标准差，实机仍需采集标定数据。

## 验证边界

旧残差检测器和旧局部 study 的探测终止时刻、载荷调度与当前实现不同，旧通过率不能沿用。
局部旁路只输出诊断，不接管目标力，也不要求先于总体判据触发。
`noslip_iterations=5` 属于既定辨识条件；不得放宽位移门槛或引入真值输入来掩盖失败。

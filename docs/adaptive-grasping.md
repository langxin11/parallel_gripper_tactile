# 自适应抓取

本主题研究如何根据载荷、接触状态与触觉反馈调整法向目标力，在既定力限幅内维持抓取。
[动态目标力跟踪](force-tracking.md)负责跟踪给定目标，本主题关注目标如何产生与更新。

## 三条实验路线

| 路线 | 在线依据与作用 | 当前能力边界 | 详细说明 |
| --- | --- | --- | --- |
| Oracle 目标力调度 | 使用已知摩擦系数与切向载荷需求生成目标力，作为参考基线。 | 读取真值摩擦，不属于在线辨识，也不自动构成性能上界。 | [Oracle 抓取目标力调度](force-scheduling.md) |
| 切向扰动下的触觉增力 | 根据触觉剪切变化更新有限目标包络，应对稳定夹持后的载荷变化。 | 不估计摩擦；实际目标只增不减，触发判据不构成真实微滑证明。 | [切向扰动下的触觉增力](tangential-disturbance.md) |
| 触觉接触变化检测与摩擦能力估计 | 固定预载下慢速探测，确认接触变化后冻结摩擦候选；保持阶段以实测切向力调度目标。 | 是接触变化／起滑代理；候选不是有概率保证的摩擦下界，未确认时显式回退。 | [纯触觉接触变化检测、摩擦能力估计与力调度](friction-estimation.md) |

三条路线属于同一研究主题，但使用独立的实验协议与验收口径，不能视为已经串联的统一控制器。
局部起滑旁路诊断也不等于总体检测，尚不能据此宣称局部摩擦候选已经接管目标力。

## 如何选择与比较

- 检查已知摩擦时的目标力公式与载荷响应，使用 Oracle 基线。
- 检查无需摩擦辨识的触觉增力响应，使用切向扰动实验。
- 检查触觉接触变化、摩擦候选与估计值调度，使用摩擦估计实验。

运行命令、参数、公式和结果只在对应专题维护。本页不复制默认值、结果表或条件矩阵。
跨路线比较前应对齐物体、材料、载荷协议、初始抓力、控制器和评价窗口；各自的 `passed`
不能直接用来排名。仿真真值用于场景与离线评价的范围，应与各路线允许的在线输入分别说明。

DMgripper 真机的触觉动态增力操作见[通用抓取实验](dmgripper-experiments.md)；
共享策略边界见[共享控制核](dm-shared-control.md)。共享计算实现不代表三条仿真路线均已完成实机验证。
新实验的证据与阶段性判断进入[科研报告](reports.md)，稳定方法和适用边界再更新到对应专题。
